# 八字成稿與讀盤課試讀版

想先讀一篇？從「兩個人都出了力，為什麼還覺得對方沒做到」開始。兩張盤只換出生時刻。一篇請讀者找出漏掉的交接，另一篇請對方說說，哪件事原本想自己決定。打開段後的舊稿，就能看到原先這兩張盤拿到什麼建議。[六對完整命例](readings.md)

想學會自己讀盤？從同一天的卯時與辰時開始。兩盤各有一合一沖，你能說出沖到底落在哪兩柱嗎？接著找甲日的正官，再拿《窮通寶鑑》的原表對照現代盤。每課都有圖、原典位置、練習和可展開的答案。[三堂讀盤課](lessons.md)

**已報名試讀的人，請用主持人私下傳給你的檔案。** 公開原始碼含命例、題庫和給分標準，先讀會影響結果。

## 這次怎麼比較

成稿組 30 位讀者，各讀同一張盤的兩種寫法。對照段落取自 v2.1.0 相同章節的第一則生活建議，保留原題、建議和附帶的盤面說明；試讀稿使用相同版面。有三對感情、兩對性格和一對工作命例。另換一對日期不同的試讀稿，隔天測自由回憶與配對。新舊篇幅自然不同，偏好結果包含篇幅與文風的影響。

另一組 30 位初學者先讀三堂課，一週後用三張陌生盤作答。另由兩位熟悉子平法且未參與寫作的審讀者查原典與判斷。預定門檻與收卷方式公開在[主持人手冊](HOST.md)。這批材料可供招募；真人結果要等收卷後才知道。

## 重製與核對

需 Python 3.8+、Node.js 20+、Chrome 或 Chromium。若重放發行檔，另需 zstd。各指令從本目錄執行。套件產生器每次重新隨機分派，請給它一個尚不存在的輸出目錄；同一輪持續使用第一次產出的分派表。

```sh
python3 -m unittest -v test_pilot
python3 materials.py
python3 kit.py /tmp/bazi-pilot-round-1
node print.cjs /tmp/bazi-pilot-round-1
python3 /tmp/bazi-pilot-round-1/主持人專用/score.py
```

可用 `CHROME` 指定瀏覽器執行檔。列印工具在各份 HTML 旁產生同名 PDF。實際發送只給該代號、該輪的 PDF。主持人手冊含可以直接轉傳的三則招募訊息。

`charts.json` 收錄十二盤試稿及六個額外教學／測驗輸入。每段的 `checks` 在自己盤上應全部成立，換成配對盤後至少一項失效。兩個古例直接按原書干支轉錄，不反推公曆生日。用以下指令核對凍結的盤面與舊稿。將發行版兩個 manifest 放在資料目錄根層，並依 manifest 內路徑放好涉及的年份檔；無須下載整庫。[v2.1.0 發行檔](https://github.com/openfate-ai/bazi-engine/releases/tag/corpus-v2.1.0)

```sh
python3 freeze.py /path/to/unpacked-release
```
